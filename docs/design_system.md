# Design system

- Кольори формуються з `ThemeData.colorScheme`.
- Компоненти не містять жорстко заданої палітри застосунку.
- Базовий радіус карток: 20 px.
- Відступи інтерфейсу: 8 / 12 / 16 / 20 / 24 px.
- `CustomButton` має стилі `primary`, `secondary`, `danger`, `outline`.
- `ProfileWidget` має `compact` та `expanded` режими.
